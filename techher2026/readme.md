# Purpose
The purpose of the instructions created for these use cases it to promote Copilot and other AI tools to support someone returning from extended leave (or even standard).

# Prerequisites
Each prompt will specify which application to use. These examples were used in the following applications based on the data access needed:
Microsoft Copilot (consumer version available for free) https://copilot.microsoft.com/.
Microsoft 365 Copilot Basic (available as part of the M365 licence (e.g. E3, E5, A1, A5): https://m365.cloud.microsoft/chat.
Microsoft 365 Copilot Premium licence with access to your business data such as email, Teams meetings, OneDrive/SharePoint content: https://m365.cloud.microsoft/chat.

# Method
Copy the prompt using the Copy raw file icon (small overlappring documents image) in the top right corner of the prompt code page or select Copy from the drop down menu using the ellipsis (three dots ... ) then paste into your application then run.
